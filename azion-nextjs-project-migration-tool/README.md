# Azion Implementation Portal (Next.js Static Export)

Este projeto foi convertido para **Next.js 14 com Static Export** para compatibilidade nativa com o importador de repositórios do **Azion Console (Import from GitHub)**.

## Configuração no Azion Console (Import from GitHub)

- **Preset:** `Next` (ou `Next.js`)
- **Root Directory:** `./`
- **Build Command:** `npm run build` ou `npx --yes @aziontech/bundler build --preset next`
- **Install Command:** `npm install`
